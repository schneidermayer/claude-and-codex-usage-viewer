# 2.0

- Renamed the app and repository to Claude and Codex Usage Viewer.
- Add, remove, and configure one to three accounts in any mix of Claude and Codex. Existing Codex connections are preserved; new installations start with one account.
- Claude sign-in uses private account storage and supports the browser authentication-code step. Claude accounts show five-hour and weekly usage when reported, including model-specific limits.
- Small and Large widgets adapt to the configured accounts and identify each provider. Claude plans retain their names; credits and earned resets remain specific to Codex.
- Separate executable settings for Claude and Codex. Removing an account also works when its CLI is unavailable.

Requires macOS 27 or later and the CLI for each provider you use. Claude Code 2.1.268 or later is required. The download supports Apple silicon and Intel Macs.

When upgrading from 1.x, quit and remove **Codex Usage Viewer.app** from Applications, then install **Claude and Codex Usage Viewer.app**. Account data stays in its existing location. If existing widgets remain stale after the rename, log out of macOS and back in, or restart, to clear the cached old app location.
