# Claude and Codex Usage Viewer 2.3.1

- Check GitHub for a newer release when the app opens. When an update is available, a small link beside the version opens its release page.
- Add **Check for Updates…** to the app menu and an update status with a manual check in Settings.
- Improve widget contrast in light appearance with a 5% background tint and a 12% usage fill across Small, Large, and Dashboard.

Download and install updates manually from the linked release page. Quit and replace the app in Applications; account connections are preserved.

Requires macOS 27 or later and the CLI for each provider you use. The signed and notarized download supports Apple silicon and Intel Macs.
